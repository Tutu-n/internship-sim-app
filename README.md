# Internship Sim App

Full-stack application with a React frontend and Node.js/Express backend.

## Structure

- `frontend/`: React + Vite client
- `backend/`: Node.js, Express, MongoDB server

## Getting Started

### Backend
1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env` and fill in your connection string
4. `npm run dev` (or `npm start`)

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
